Help & Privacy
What is an API Key?
An API key is a password that lets SynapseGPT talk to an AI service on your behalf. You create one for free (or low cost) in the provider's dashboard, paste it here, and the add-on sends your questions directly to that service — no middleman.
Which provider should I choose?
OpenAI (gpt-4o-mini) — fast & affordable, great all-rounder.
Google Gemini (flash) — free tier available, very capable.
Anthropic Claude — strong at nuanced explanations.
OpenRouter — access many models with one key, includes free options.
Ollama — runs 100% locally on your machine, no key, no cost, no data leaves your device.
Local AI with Ollama
Ollama runs open-source models (Llama, Gemma, Qwen…) directly on your computer. Nothing is sent to the internet — ideal for sensitive material. Select Ollama as provider and click the link to install it, then pull a model from the wizard. Recommended starter: gemma2:2b (~1.6 GB).
Privacy & Data Security
Your API key is stored only on this device in Anki's local config — it is never uploaded to any server by this add-on.

When you send a message, your question and card content go directly to the provider you chose (OpenAI, Google, etc.) under their privacy policy. If privacy is critical, use Ollama — everything stays local.

SynapseGPT does not collect analytics, logs, or usage data.
Quick Tips
• Open a card in the reviewer, then use the action buttons (Short, Concise…) to instantly analyse it.
• Set keyboard shortcuts for buttons in the Manage menu.
• Switch Card Content to "Front & Back" for richer context.
• Adjust Chat Font Size in Settings if text feels too small or large.
