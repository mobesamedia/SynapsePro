Help & Privacy
What is an API Key?
An API key is a password that lets SynapseGPT talk to an AI service on your behalf. You create one in the provider's dashboard, paste it here, and the add-on sends your questions directly to that service.
Which provider should I choose?
OpenAI (gpt-5.4-mini) is a fast all-rounder. Google Gemini offers a capable free tier. Anthropic Claude is strong at nuanced explanations. OpenRouter provides many models with one key. Ollama runs locally without a key or usage fees.
Local AI with Ollama
Ollama runs open-source models directly on your computer. Nothing is sent to an online AI provider. Select Ollama, open the setup assistant, and install a model such as gemma2:2b.
Privacy & Data Security
Your API key is stored in your local Anki profile and is never uploaded by SynapsePro. Questions go directly to the selected provider. Visible card text is included only when you use a Quick Action or enable current-card context. The chat assistant does not collect chat analytics, logs, or conversations.
Common Questions
Chat subscriptions and API access are separate products with separate billing. Google Gemini and some OpenRouter models offer free tiers; Ollama runs locally for free. API credit is managed in the selected provider's dashboard.
Quick Tips
Open a reviewer card before using Quick Actions. Enable current-card context for your own card questions. Manage button shortcuts in the Manage dialog. Choose Front & Back for richer context and adjust the chat font size in Settings.

Current card context
When enabled, the text of the card currently open in Anki is sent in the background with each question and used by the AI. It stays hidden from the chat and is read fresh when you press Send. Your selected AI provider receives this text; with Ollama it stays on your computer.
